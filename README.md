## Manual Install (Early Access / Development)

Use this if you want the latest version before it hits the stores, or if you want to run it locally.

### Chrome / Edge

1. Click the green **Code** button → **Download ZIP**
2. Extract the ZIP folder
3. Open Chrome or Edge → go to `chrome://extensions`
4. Enable **Developer Mode** (top right toggle)
5. Click **Load Unpacked** → select the extracted folder
6. Done! The extension icon will appear in your toolbar.

### Firefox

1. Click the green **Code** button → **Download ZIP**
2. Extract the ZIP folder
3. Open Firefox → go to `about:debugging`
4. Click **This Firefox** (left sidebar)
5. Click **Load Temporary Add-on**
6. Open the extracted folder → select `manifest_firefox.json`
7. Done! The extension icon will appear in your toolbar.

> **Note:** Firefox temporary add-ons are removed when the browser closes. For a permanent install, use the [Firefox Add-ons store](https://addons.mozilla.org/en-US/firefox/addon/wa-media-downloader/) instead.

## How to Use

1. Open [WhatsApp Web](https://web.whatsapp.com) and go to any chat
2. Scroll up to load the media you want to download
3. Click the extension icon in your toolbar
4. Click **Scan** — it will detect all docs, images, videos, and audio
5. Select the file types you want
6. Click **Download Selected** — files are saved to your `Downloads/WA_Media/` folder
